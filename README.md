# Familie, Wirtschaft und Diplomatie

Ein Blog über Deutschland in Zahlen. Die Artikel behandeln Themen aus den Bereichen
Familie, Wirtschaft und Diplomatie, zum Beispiel Geburtenrate, Wirtschaftswachstum
oder Deutschlands wichtigste Handelspartner.

Im Mittelpunkt stehen Fakten: kurze, neutrale Texte mit selbst erstellten Diagrammen.
Alle Zahlen stammen aus öffentlichen Quellen, die in jedem Artikel verlinkt sind.

**Zur Seite:** <https://henningbro.github.io/familie-wirtschaft-diplomatie/>
